How to Edit the Code

There are several ways to modify the application.

Use Your Local Development Environment

You can clone the repository and run the project locally.

Requirements

Make sure you have installed:

Node.js

npm

You can install Node.js using nvm:
https://github.com/nvm-sh/nvm#installing-and-updating

Installation Steps
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd <YOUR_PROJECT_NAME>

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev

The development server will start with live reloading and a local preview.
